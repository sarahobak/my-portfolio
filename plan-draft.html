01 · Concept

서비스 콘셉트와 핵심 방향

서비스명Gift Finder
목적선물을 고르기 어려운 사람에게 상황과 예산에 맞는 선물 아이디어를 빠르게 제안
타깃20~30대. 연인·친구·동료·부모님 선물을 1년에 여러 번 고민하는 사람
서비스 유형상품을 직접 팔지 않는 선물 추천·정보 안내 웹페이지
제작 방식AI 웹사이트 제작 도구만으로 만드는 한 페이지 (로그인·결제·데이터베이스·외부 API 없음)

핵심 가치와 화면에서 지키는 방법

간편함

질문 3개, 클릭 5번이면 결과. 화면 이동 없이 한 페이지 안에서 끝

세련된 디자인

웜 아이보리 + 올리브 그린 중심, 넉넉한 여백, 장식 최소화

신뢰감

추천 이유를 한 줄씩, "판매하지 않음 · 가격은 참고용"을 숨기지 않고 표시

편리한 탐색

조건으로 찾기와 상황별로 둘러보기, 두 가지 길만 제공

톤 앤 매너

  • 차분하게: 느낌표·이모지 남발 금지. "선물 고민, 3분이면 충분해요"처럼 담백한 문장
  • 구체적으로: "좋은 선물" 대신 "매일 쓰는 물건이라 부담 없이 고마움을 전할 수 있어요"
  • 유치하지 않게: 캐릭터·무지개색 파스텔·과한 움직임 사용하지 않음
02 · Structure

전체 사이트 구조와 상단 메뉴 설계

검토한 메뉴 5개 중 실제로 필요한 것만 남겨, 상단 메뉴는 3개 + 버튼 1개로 간결하게 구성합니다.

검토한 메뉴결정이유
홈로고로 대체로고를 누르면 맨 위로. 메뉴 칸을 따로 쓰지 않음
선물 찾기넣음서비스의 핵심 기능
상황별 선물넣음조건을 고르기 전 둘러보고 싶은 사람을 위한 두 번째 길
예산별 선물선물 찾기에 합침예산은 선물 찾기의 질문 중 하나라 메뉴가 겹침
서비스 소개"이용 방법"으로 합침소개와 사용법을 한 영역에 모아 메뉴 수를 줄임

추천 규칙 · 미리 준비한 선물 목록 사용

  1. 받는 사람 · 예산 · 어떤 날이 모두 맞는 선물 중 3개를 무작위로
  2. 모자라면 '어떤 날'을 빼고 채움
  3. 그래도 모자라면 예산 한 칸 아래에서 채우고 "비슷한 선물도 함께 골랐어요" 안내
  4. "다른 선물 3개 보기"는 이미 본 선물을 빼고 다시 3개. 다 보면 처음부터 다시 섞음

선물 목록 (60개 내외)

칸: 선물 이름 · 받는 사람(여러 개) · 예산(하나) · 어떤 날(여러 개) · 가격대 · 추천 이유 · 태그 2개 · 아이콘. 받는 사람과 예산의 모든 조합에서 최소 3개가 나오게 준비합니다.

사용자 경험과 PC·모바일 반응형 설계

클릭 다섯 번이면 추천 결과까지. 새 페이지 · 팝업 · 회원가입 없이 한 화면 흐름 안에서 끝납니다.

선물을 찾는 전체 과정

  1. 들어오기제목과 시작 버튼이 바로 보임클릭 0
  2. 시작하기선물 찾기 영역으로 이동클릭 1
  3. 받는 사람칩 선택, 번호 원에 ✓클릭 2
  4. 예산요약이 바로 바뀜클릭 3
  5. 어떤 날추천 버튼 활성화클릭 4
  6. 추천받기0.4초 뒤 카드 3개 + 결과로 이동클릭 5

처음 온 사람도 바로 이해하게

  • 메인 소개의 "회원가입 없음 · 판매 없음 · 1분 완성"
  • 질문 번호 1 · 2 · 3이 고를 때마다 ✓로 바뀌어 진행 상황이 보임
  • "2개 더 고르면…" 안내로 남은 일을 알려 줌
  • 결과 제목에 고른 조건을 문장으로 다시 보여 줌

불필요한 클릭과 이동 줄이기

헤더(고정): 왼쪽 선물 상자 선 아이콘 + "Gift Finder" 로고, 오른쪽에 메뉴 "선물 찾기 · 상황별 선물 · 이용 방법"과 올리브색 알약 버튼 "추천받기". 지금 보고 있는 영역의 메뉴는 올리브색 밑줄. 모바일에서는 메뉴를 ☰ 버튼으로 접고, 누르면 아래로 펼쳐지는 패널로.

영역 순서:

  1. 메인 소개: 작은 라벨 "GIFT FINDER", 제목 "고민은 줄이고, 마음은 정확하게", 설명 한 줄, 버튼 "선물 추천 시작하기"(주) · "이용 방법 보기"(보조), 그 아래 "회원가입 없음 · 판매 없음 · 1분 완성". PC는 오른쪽에 선물 카드 3장이 겹친 미리보기 그림.
  2. 선물 찾기: 흰 카드 한 장 안에 질문 3개를 알약 모양 칩으로. ① 누구에게 주나요? 연인·친구·부모님·직장 동료·형제자매·나에게 ② 예산은 얼마인가요? 3만 원 이하·3~5만 원·5~10만 원·10만 원 이상 ③ 어떤 날인가요? 생일·기념일·감사·집들이·축하(취업·승진)·응원·위로. 질문마다 하나만 선택. 카드 아래에 고른 조건 요약과 "선물 3개 추천받기" 버튼. 3개를 다 고르기 전에는 버튼을 비활성으로 하고 "N개 더 고르면 추천받을 수 있어요"를 보여 줘.
  3. 추천 결과: 버튼을 누르면 0.4초 로딩 후 나타나고 그 위치로 스크롤. 제목 "[받는 사람]에게 줄 [예산] [어떤 날] 선물이에요", 카드 3개(PC 가로 3칸, 모바일 세로), 아래에 "다른 선물 3개 보기" · "조건 바꾸기" 버튼.
  4. 상황별 선물: 카드 6장(생일·기념일·감사·집들이·축하·응원·위로). 카드마다 선 아이콘, 이름, 한 줄 설명, 대표 선물 3개, "이 상황으로 찾기 →". 누르면 선물 찾기의 '어떤 날'을 그 상황으로 미리 선택하고 선물 찾기 영역으로 이동.
  5. 이용 방법: 3단계(조건 고르기 → 추천받기 → 쇼핑몰에서 확인하기), 서비스 소개 한 문단(판매하지 않음, 광고비로 순서를 바꾸지 않음), 펼쳐 보는 자주 묻는 질문 4개, "지금 선물 찾기" 버튼.
  6. 하단 안내 띠: "Gift Finder는 상품을 판매하지 않아요. 가격대는 참고용이며 실제 가격은 쇼핑몰에서 확인해 주세요."
  7. 푸터: 로고, 한 줄 소개, 메뉴 반복, © 2026 Gift Finder.

선물 카드: 모서리 20px, 1px 테두리, 위에 4:3 그림 영역(보조 배경색 + 올리브 선 아이콘), 왼쪽 위 "추천 1" 배지, 선물 이름, 가격대, 추천 이유 한 줄, 태그 2개, 맨 아래 "상품 찾아보기 ↗"(네이버쇼핑 검색 결과를 새 창으로). 마우스를 올리면 2px 위로.

버튼과 칩: 모두 알약 모양. 큰 버튼 높이 56px, 보통 48px, 칩 44px. 선택된 칩은 올리브 배경 + 흰 글자. 키보드 초점은 올리브 2px 테두리.

추천 규칙: 아래 선물 목록에서 세 조건이 모두 맞는 선물 중 3개를 무작위로. 모자라면 '어떤 날'을 빼고, 그래도 모자라면 예산 한 칸 아래에서 채우고 "비슷한 선물도 함께 골랐어요"라고 알려 줘. "다른 선물 3개 보기"는 이미 본 선물을 빼고 다시 3개.

반응형: 1024px 이상 PC, 768~1023px 태블릿, 767px 이하 모바일. 모바일은 모두 1단, 상황 카드만 2칸. 누르는 것은 모두 44px 이상.

접근성: 키보드로 모두 조작 가능, 질문과 칩을 묶어 화면 읽기 프로그램이 읽을 수 있게, 결과가 나타나면 알려 주기, 움직임 줄이기 설정 존중.

다 만든 뒤 확인할 것

  • 첫 화면에서 스크롤하지 않아도 선물 추천 시작하기가 보인다
  • 메뉴 3개가 맞는 영역으로 이동하고, 현재 메뉴에 밑줄이 생긴다
  • 세 가지를 다 고르기 전에는 추천 버튼이 눌리지 않는다
  • 결과가 항상 3개, 다른 선물 보기에서 같은 선물이 바로 반복되지 않는다
  • 상황 카드를 누르면 '어떤 날'이 미리 선택되어 있다
  • 휴대폰에서 메뉴가 ☰으로 접히고 결과 카드가 세로로 쌓인다
  • 색이 10가지에서 벗어나지 않고 이모지가 없다
  • 하단에 "판매하지 않음 · 가격은 참고용" 안내가 있다
