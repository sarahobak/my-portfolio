화면 구성

한 페이지 안에서 위에서 아래로 쌓이는 구조입니다. 계산 종류를 바꿔도 페이지는 그대로이고, 가운데 계산기 카드 안의 내용만 바뀝니다.

01상단 바왼쪽에 로고 "말랑계산기", 오른쪽에 소개 문구 "쉽고 빠른 생활 계산"
02계산 종류 선택 버튼알약 모양 버튼 3개를 가로로 나란히. 선택된 버튼만 라벤더로 채움
03계산 결과 표시 영역계산기 카드 맨 위. 입력 중인 식은 작게, 결과는 크게 오른쪽 정렬
04계산기 화면선택한 계산 종류에 맞는 버튼판 또는 입력칸
05사용 팁"할인율은 %만 넣으면 돼요" 같은 한 줄 팁 2~3개
06광고 자리계산기 카드 아래. 처음에는 비워 두거나 추천 링크로 사용
07하단사이트 소개, 개인정보처리방침, 문의 링크

➕ 사칙연산
4칸 × 5줄 버튼판
숫자는 흰색, 연산(÷ × − +)은 민트, =은 라벤더, C·⌫는 핑크. 결과 영역 위 줄에 12 × 3, 아래 줄에 36처럼 식과 답을 함께.
🏷️ 할인율
입력칸 2개 + 빠른 선택
원래 가격·할인율을 넣으면 할인 금액과 최종 가격(가장 크게)을 표시. 아래에 10% 20% 30% 50% 칩. 예: 30,000원 20% 할인 → 24,000원
⚖️ 비율
작은 탭 2개
몇 %일까? 전체·부분 값 입력 → "50 중 15는 30%"
비례식 A : B = C : ? → "2 : 3 = 8 : 12"
이용 흐름
STEP 1사이트 접속기본으로 사칙연산 화면이 열림
STEP 2종류 선택필요한 계산 종류 버튼 누르기
STEP 3숫자 입력버튼판 또는 입력칸 사용
STEP 4결과 확인사칙연산은 =, 나머지는 즉시 표시
STEP 5초기화C 또는 "다시 계산" 버튼
