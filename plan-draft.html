영역별 설명

①상단 제목로고, 큰 제목 "어떤 선물이 좋을까요?", 작은 설명 한 줄
②조건 선택 카드질문 3개를 한 카드 안에. 질문마다 칩을 가로로 나열하고 하나만 선택. 아래에 고른 조건 요약
③추천 버튼폭이 넓은 둥근 버튼. 세 가지를 모두 고르기 전에는 흐리게
④추천 결과결과 제목 + 카드 3개. 버튼을 누르면 바로 나타나고 화면이 결과 위치로 부드럽게 이동
⑤결과 아래 버튼다른 선물 보기(같은 조건으로 다시 3개) · 처음부터 다시
⑥광고 자리결과 아래 배너 1개, 처음에는 비워 둠
⑦하단짧은 소개, 제휴 링크 안내 문구, 문의

결과 카드는 PC에서 가로 3개, 모바일에서 세로로 쌓아요. 카드는 아래에서 위로 살짝 떠오르며(0.3초) 나타나요.

이용 흐름

  1. 페이지 접속, 질문 3개가 바로 보임
  2. 받는 사람 → 예산 → 목적 칩 고르기
  3. "선물 추천받기" 누르기
  4. 아래에 선물 3개, 화면이 결과로 이동
  5. 상품 보러 가기 또는 다른 선물 보기

핵심 기능

기능설명
받는 사람 선택부모님 · 연인 · 친구 · 직장 동료 · 선생님 · 아이 중 하나
예산 선택1만 원 이하 · 1~3만 원 · 3~5만 원 · 5~10만 원 · 10만 원 이상 중 하나
선물 목적 선택생일 · 감사 · 축하(입학·취업) · 기념일 · 응원·위로 · 명절 중 하나
추천 버튼 활성화세 가지를 모두 골라야 버튼이 눌림
선물 3개 추천미리 준비한 목록에서 조건에 맞는 선물 3개 표시

처음부터 다시선택을 모두 지우고 맨 위로 이동

선물 목록 준비 방법

선물 목록은 JavaScript 파일 안에 표처럼 적어 둡니다. 처음에는 60개 정도면 충분해요.

선물 이름받는 사람예산목적추천 이유링크
향초 선물 세트친구, 연인, 동료1~3만 원생일, 감사, 응원부담 없이 분위기를 선물할 수 있어요(비워 둠)
안마기부모님10만 원 이상생일, 명절, 감사매일 쓰는 효도 선물이에요(비워 둠)
텀블러동료, 친구, 선생님1~3만 원감사, 축하실용적이고 누구나 잘 써요(비워 둠)

한 선물에 받는 사람·목적은 여러 개를 적을 수 있어요(예산은 하나). 나중에 제휴 링크를 넣을 수 있게 "링크" 칸을 처음부터 만들어 둬요.

추천 규칙

  1. 받는 사람 · 예산 · 목적이 모두 맞는 선물을 찾는다
  2. 그중 3개를 무작위로 골라 보여준다
  3. 3개가 안 되면 목적 조건을 빼고 다시 찾아 채운다
  4. 그래도 모자라면 예산을 한 칸 아래까지 넓혀 채운다
  5. "다른 선물 보기"는 이미 보여준 선물을 빼고 다시 3개를 고른다

목록을 만들 때 조합마다 최소 3개가 나오는지 표로 확인해 두면 3~4번 규칙은 거의 쓸 일이 없어요.

  • 화이트#FFFFFF · 카드·보조 버튼

광고와 제휴 링크 고려

AD광고 위치결과 아래 배너 1개, 하단 1개. 조건 선택 카드와 추천 버튼 근처에는 두지 않음
LINK제휴 링크결과 카드의 "상품 보러 가기" 버튼에 쇼핑몰 제휴 링크 연결
PREP미리 준비선물 목록에 "링크" 칸을 만들어 두고, 처음에는 쇼핑몰 검색 결과 주소를 넣어 둠
NOTE안내 문구제휴 링크를 쓰면 결과 아래와 하단에 "이 페이지의 링크로 구매하면 수수료를 받을 수 있어요" 같은 안내를 꼭 표시

추천은 선물 목록 기준으로만 하고, 수수료가 높은 상품을 억지로 앞에 두지 않아요. 믿을 수 있어야 다시 찾아와요.
