포트폴리오 사이트 기획서 (초안)

작성일: 2026-10-27 · 상태: 초안. 아래 "정해야 할 것" 항목을 채우면서 다듬어 갑니다.

1. 한 줄 요약

이모티콘 작가로서 "내가 무엇을 만들 수 있는 사람인지"를 보여주고, 보는 사람이 바로 연락하거나 채용·협업으로 이어지게 만드는 사이트.

2. 누가 보는가 (타깃)

방문자궁금한 것사이트에서 해줘야 할 것
채용 담당자어떤 스타일로, 어느 수준까지 작업하는지대표 작업을 빠르게 보여주기, 이력서 다운로드
협업·외주를 원하는 사람내 브랜드·프로젝트와 잘 맞는지, 의뢰할 수 있는지스타일의 폭 보여주기, 외주 문의 방법 안내
지인요즘 무엇을 하고 있는지최신 작업 보여주기, SNS·스토어로 연결

공통점: 모두 "이 사람이 뭘 할 수 있지?"를 궁금해합니다. 그래서 첫 화면에서 작업물이 바로 보여야 합니다.

3. 무엇을 보여주는가 (콘텐츠)

핵심 분야

  • 이모티콘 제작 (현재 유일하게 확정된 분야)
  • 지원 직무는 아직 정하지 않음. 이모티콘 작업을 중심에 두되, 이후 관련 분야(캐릭터 디자인, 일러스트, 굿즈 디자인 등)로 넓힐 수 있게 구조를 잡아 둡니다.

들어갈 내용

  1. 대표 이모티콘 작업 (3~6개 세트)
    • 세트별로 캐릭터 이름, 콘셉트, 대표 이미지 또는 움직이는 GIF
    • 기획 의도, 작업 과정(스케치 → 완성), 출시 여부나 반응
  2. 소개 (About): 어떤 캐릭터를 즐겨 만드는지, 작업 스타일, 사용하는 도구
  3. 이력서: 웹에서 바로 볼 수 있는 요약본과 PDF 다운로드

4. 보고 나서 무엇을 하길 바라는가 (행동 유도)

방문자 유형에 맞춰 아래 행동을 모두 열어 둡니다.

행동주로 하는 사람위치
📧 이메일로 연락하기채용 담당자, 협업자상단 메뉴, 맨 아래
📄 이력서 다운로드채용 담당자소개 페이지, 상단 메뉴
💼 외주 문의하기협업자별도 문의 섹션 (가능한 작업, 진행 방식 안내)
📷 인스타그램 방문지인, 협업자맨 아래, 소개 페이지
🛒 이모티콘 스토어 방문모두각 작업 상세 페이지, 맨 아래

주의: 버튼이 5개나 되면 시선이 흩어질 수 있습니다. 가장 중요한 1~2개(예: 이메일 연락, 이력서)를 눈에 띄게 하고, 나머지는 작게 배치하는 것을 추천합니다.

5. 사이트 구조 (안)

홈
├─ 첫 화면: 한 줄 소개 + 대표 이모티콘 (움직이는 이미지)
├─ 작업 목록 (썸네일 그리드)
└─ 연락하기 버튼

작업 상세 (세트별)
├─ 콘셉트 / 캐릭터 소개
├─ 전체 이모티콘 보기
├─ 작업 과정
└─ 스토어 링크

소개 (About)
├─ 자기소개 / 작업 스타일 / 도구
└─ 이력서 다운로드

문의 (Contact)
├─ 이메일
├─ 외주 문의 안내
└─ 인스타그램 / 스토어 링크

6. 정해야 할 것 (다음 단계)

  • 지원 직무 정하기: 이모티콘 작가, 캐릭터 디자이너, 일러스트레이터 중 무엇을 목표로 할지 정하면 소개 문구와 강조할 부분이 정해집니다.
  • 보여줄 작업 고르기: 지금 가진 이모티콘 작업이 몇 세트인지, 출시된 것이 있는지 정리합니다.
  • 가장 중요한 행동 1~2개 고르기: 구직이 목표라면 "이메일 연락"과 "이력서 다운로드"를 추천합니다.
  • 연결할 계정 준비: 이메일, 인스타그램, 이모티콘 스토어 주소
  • 사이트 분위기 정하기: 색감, 톤 (귀엽게 / 깔끔하게 등). 이모티콘 스타일과 맞추는 것이 좋습니다.
  • 제작 방법 정하기: 노코드 도구(예: Notion, Framer, Wix) 또는 직접 코딩
