투여 일정 계산 규칙

규칙구현
다음 예정일가장 최근의 유효한 실제 투여일 + 투여 간격(일)
예시2026-10-28 + 7일 = 2026-11-04
남은 날짜오늘과 다음 예정일의 달력상 날짜 차이 (시각은 보지 않음)
상태0일 오늘 예정 · 남음 D-N · 지남 예정일 지남
이후 예정일다음 예정일부터 같은 간격으로 4회
유효한 기록삭제하지 않았고, 날짜가 올바르며, 오늘 이전인 기록
기준 기록유효한 기록 중 날짜가 가장 늦은 것 (목록에 계산 기준 표시)
예정일과 실제 투여일따로 관리. 예정일은 저장하지 않고 매번 기록에서 계산
기록 추가·수정·삭제바뀔 때마다 즉시 다시 계산
미래 날짜실제 투여일로 등록 불가 (입력칸 최대값 + 저장 전 검사, 안내 문구)
같은 날짜 중복등록 불가, 기존 기록을 수정하도록 안내
투여 간격1~28일 사이 정수, 기본 7일
누락·일정 변경새로운 투여 지침을 자동으로 만들지 않음. 예정일이 지나면 "기록을 추가하고 의료진 안내를 따르세요"만 표시

날짜 오류를 막는 방법

  • 날짜는 YYYY-MM-DD 문자열로만 저장하고, 계산할 때 UTC 자정 기준 '날짜 번호' 로 바꿔 더하고 뺀다 → 서머타임·시간대와 무관
  • '오늘'은 사용자 기기의 현지 날짜(년·월·일)만 사용
  • 월말·연말·윤년은 Date.UTC가 처리하고, 2026-02-30 같은 없는 날짜는 거절
  • 자정이 지나면 1분 안에 오늘 날짜와 남은 날짜를 다시 계산

기록을 덮어쓰지 않는 방법

  • 수정: 이전 값(날짜·용량·메모·수정 시각)을 그 기록의 history에 남기고 새 값으로 바꿈. 다른 기록은 건드리지 않음 (목록에 "수정 N회")
  • 삭제: 실제로 지우지 않고 deletedAt 표시만 → 계산에서 제외. 6초 동안 되돌리기, 이후에도 "삭제한 기록"에서 복원
  • 복원: 같은 날짜의 다른 기록이 있으면 복원하지 않고 안내
  • 계산 버튼: 입력한 날짜의 기록이 없을 때만 새로 추가. 있으면 그대로 두고 용량·간격 설정만 저장

디자인 시스템 · Soft Lavender Diary

콘셉트: 연보라와 라벤더를 중심으로 밝고 부드러운 다이어리 분위기를 만들고, 진한 보라색은 최소화한다. 기존 기능, 메뉴 구조, 날짜 계산 로직은 바꾸지 않고 전체 페이지의 색상만 일관되게 수정한다.

UI/UX 디자인 원칙

  • 넉넉한 여백: 영역 사이 48~64px, 카드 안쪽 24px
  • 절제된 장식: 사진·일러스트·그라데이션 없음. 장식은 짧은 강조선 정도만
  • 진한 보라 최소화: 넓은 면은 연보라·라벤더, 진한 색은 작은 글자와 선에만
  • 일관된 카드 디자인: 흰 배경 · 1px #E7E0EF 테두리 · 모서리 14px로 통일
  • 계산기 우선: 입력 카드(포인트 테두리)와 결과 카드(주요 컬러 배경 + 72px 날짜)만 다른 카드보다 강하게 표현
  • 날짜와 기록 구분: 실제 투여일 = 포인트 컬러로 채움 · 다음 예정일 = 보조 컬러 · 이후 예정일 = 점선 테두리 · 오늘 = 라벤더 잉크 테두리 + 작은 점
