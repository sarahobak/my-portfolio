⑤ 즐겨찾기

카테고리 필터 칩, 색 점으로 카테고리 구분. 비어 있으면 여행 가방 일러스트.

이용 흐름

  1. 나라 선택
  2. →
  3. 상황 고르기 🍜
  4. →
  5. 문장 찾고 🔊 듣기
  6. →
  7. 크게 보기 · 보여주기 모드
  8. →
  9. ⭐ 저장 → 즐겨찾기에서 꺼내기

모든 화면 아래에 하단 탭 바(🏠 홈 · ⭐ 즐겨찾기 · 🌏 나라 변경)를 고정해 어디서든 한 번에 이동해요. 보여주기 모드는 외국어 문장만 화면 가득 띄워 현지인에게 휴대폰을 보여주는 기능이에요.

모바일 우선 설계

  • 📏화면 폭에 꽉 차게 1단. PC는 가운데 폭 약 420px
  • 👍🔊 · ⭐ · 탭 바는 엄지가 닿는 아래쪽에
  • 🔠버튼 최소 44px, 글자 최소 15px
  • 📶데이터가 약해도 빨리 열리게 이미지는 가볍게

배경과 카드는 흰색으로 비우고 파스텔은 카테고리 구분에만 써요. ②·③·⑤ 화면에서 같은 색을 써서 "하늘색 = 공항"처럼 기억되게 해요.

🖼️ 일러스트

  • 선이 얇고 색이 연한 플랫 일러스트: 비행기와 구름, 호텔, 라멘 그릇, 쇼핑백, 택시, 구급 상자
  • 국가 선택 화면 위, 나라·카테고리 카드, 빈 즐겨찾기 화면에 사용
  • 무료 일러스트 사이트에서 같은 스타일로 통일. 상업적 이용 가능 여부와 출처 표시 조건 확인
  • 처음에는 이모지로 대신해도 괜찮아요

🃏 카드와 버튼

  • 카드 모서리 24px, 옅은 그림자, 여백 18~20px, 간격 12px
  • 카테고리 카드는 정사각형에 가깝게, 위 일러스트 · 아래 이름
  • 큰 버튼은 알약 모양, 높이 52px
  • 🔊 · ⭐ 버튼은 지름 44px 동그라미
  • 하단 탭 바 높이 64px, 선택된 탭만 오션 블루

🔤 글꼴과 글자 크기

  • 보여주기 모드 40px 이상 · 자세히 보기 문장 28px
  • 제목 22px · 카드의 뜻 17px 굵게 · 본문 15px · 발음 13px
  • 한글은 Pretendard, 외국어는 Noto Sans 계열(JP·Thai 등)을 함께 지정해 글자 깨짐 방지

🛠️문장과 발음을 위한 기술 · API

처음에 쓸 것 · 무료, 초보자용

필요한 것방법설명
외국어 문장·뜻직접 만든 JSON 목록 파일나라 → 카테고리 → 문장(외국어, 한글 발음, 로마자, 뜻) 순서로 정리. 여행 회화책·여행 안내 자료를 참고해 작성하고, 가능하면 원어민에게 확인
발음 듣기Web Speech API speechSynthesis브라우저 내장 음성 읽기. 무료, 키 필요 없음. 언어 코드(ja-JP, en-US)와 속도를 정할 수 있어 "천천히"도 가능
즐겨찾기 저장localStorage브라우저에 작은 데이터를 저장. 회원가입 없이 사용
글꼴Google FontsNoto Sans JP · Thai 등으로 외국어 글자 깨짐 방지

나중에 고려할 것 · 더 좋은 품질, 대부분 유료

목적예시메모
자연스러운 음성Google Cloud Text-to-Speech, 네이버 클로바 보이스, Amazon Polly미리 mp3 파일로 만들어 두면 매번 호출하지 않아도 됨
원어민 녹음Forvo API, 직접 녹음프리미엄 콘텐츠로 활용
번역 보조파파고 API, Google Cloud Translation, DeepL API새 문장 초안용으로만 쓰고 사람이 꼭 다시 확인
⚠️ 알아 둘 점
  • Web Speech API는 기기·브라우저마다 목소리 품질이 다르고, 특정 언어 목소리가 없는 기기도 있어요. 없으면 "이 기기에서는 발음을 들을 수 없어요" 안내를 띄워요.
  • 번역은 실시간으로 하지 않아요. 기계 번역은 여행 상황에서 어색하거나 틀릴 수 있어서, 미리 확인한 문장만 보여줘요.
  • 유료 API 키를 웹페이지 코드에 넣으면 누구나 볼 수 있어요. 키가 필요한 API는 서버가 필요하므로 1차에서는 쓰지 않아요.

💰수익화 계획

시기방식내용
방문자가 모이면광고홈과 즐겨찾기 아래 배너 1개씩. 문장 자세히 보기·보여주기 모드에는 광고 없음
그다음프리미엄 여행 회화도시별 팩(도쿄·오사카·방콕), 원어민 녹음, 알레르기·채식 등 특별 상황 문장, 오프라인 저장
함께제휴 링크여행자 보험, 유심·eSIM, 숙소 예약 등 여행 관련 제휴 안내

기본 6개 카테고리 문장은 계속 무료예요. 프리미엄 카테고리는 처음부터 🔒 "준비 중"으로 자리만 만들어 두면 나중에 추가하기 쉬워요.
