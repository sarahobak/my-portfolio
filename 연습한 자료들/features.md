## 02. 사용자 시나리오

### 지은 씨 — 가장 빠른 길

쓰는 기능: 1 조건 고르기 · 2 선물 추천 · 7 결과 공유하기

1. 퇴근길 지하철에서 링크를 연다. 첫 화면 가운데에 질문 3개가 바로 보인다.
2. `직장 동료` · `3~5만 원` · `축하`를 차례로 누른다. 다 고르니 `추천받기` 버튼이 켜진다.
3. `추천받기`를 누르니 선물 카드 3개가 나온다.
4. 카드의 가격과 추천 이유 한 줄을 훑어본다. "매일 책상에서 쓰기 좋아요"라는 이유가 마음에 든다.
5. 팀원들과 돈을 모아 사기로 했던 게 생각나서 `공유하기`를 누르고, 복사된 링크를 팀 단톡방에 보낸다.
6. 팀원들이 좋다고 하자 `상품 찾아보기 ↗`를 눌러 쇼핑몰에서 주문한다.

**결과:** 지하철 두 정거장 만에 선물을 정하고 팀원들 의견까지 받았다.

### 도현 씨 — 후보를 늘려 보는 길

쓰는 기능: 1 조건 고르기 · 2 선물 추천 · 3 ＋ 2개 더

1. 주말 카페에서 노트북으로 사이트를 연다.
2. `친구` · `3만 원 이하` · `집들이`를 고르고 추천받는다.
3. 3개 중 2개는 친구 집에 이미 있을 것 같은 물건이라 아쉽다.
4. `＋ 2개 더`를 누르니 카드 2개가 아래에 붙는다. 처음 3개도 그대로 있어서 함께 비교할 수 있다.
5. 한 번 더 눌러 7개를 본 뒤, 싸 보이지 않는 디퓨저로 정하고 `상품 찾아보기 ↗`를 누른다.

**결과:** 처음 추천이 아쉬웠지만 조건을 다시 고르지 않고 마음에 드는 선물을 찾았다.

### 민서 씨 — 꼼꼼히 비교하는 길

쓰는 기능: 1 조건 고르기 · 2 선물 추천 · 4 더 보기 · 5 다시 고르기 · 6 찜하기

1. 점심시간에 집 PC로 사이트를 연다.
2. `부모님` · `5~10만 원` · `생일`을 고르고 추천받는다.
3. 한 줄 이유만으로는 엄마가 실제로 쓸지 모르겠다. `더 보기`를 눌러 자세한 이유를 읽고, 괜찮은 선물 하나를 ♡로 찜해 둔다.
4. 조금 더 좋은 선물도 보고 싶어 `다시 고르기`를 누른다. 고른 조건이 남아 있어서 예산만 `10만 원 이상`으로 바꾼다.
5. 새로 나온 선물 중에서도 하나를 ♡로 찜한다.
6. 위쪽의 `찜 2`를 눌러 찜한 두 선물을 나란히 보고, 더 잘 쓸 것 같은 선물을 `상품 찾아보기 ↗`로 확인한다.

**결과:** 두 가지 예산의 선물을 비교해 보고 확신을 갖고 골랐다.

## 03. 기능

| 번호 | 기능 | 한 줄 설명 |
| --- | --- | --- |
| 1 | 조건 고르기 | 누구에게 · 예산 · 어떤 날을 하나씩 고른다 |
| 2 | 선물 추천 | 맞는 선물 3개를 카드로 보여 준다 |
| 3 | ＋ 2개 더 | 지금 카드는 두고 2개를 더 보여 준다 |
| 4 | 더 보기 | 카드를 펼쳐 추천 이유를 자세히 보여 준다 |
| 5 | 다시 고르기 | 조건을 바꿔서 다시 추천받는다 |
| 6 | 찜하기 | 마음에 드는 선물을 ♡로 모아 둔다 |
| 7 | 결과 공유하기 | 추천 결과를 링크로 보낸다 |

### 1. 조건 고르기

- **어디서:** 첫 화면 가운데
- **이렇게 하면:** 질문 3개에서 버튼을 하나씩 누르면
- **이렇게 돼요:** 3개를 다 고르면 `추천받기` 버튼이 켜진다
- **이럴 땐:** 덜 고르면 버튼이 꺼져 있다
- **고를 수 있는 것:** (글자 입력 없음, 질문마다 1개)
  - 누구에게: 연인 · 친구 · 부모님 · 직장 동료 · 형제자매 · 나에게
  - 예산: 3만 원 이하 · 3~5만 원 · 5~10만 원 · 10만 원 이상
  - 어떤 날: 생일 · 기념일 · 감사 · 집들이 · 축하 · 응원

### 2. 선물 추천

- **어디서:** 조건 고르기 바로 아래
- **이렇게 하면:** `추천받기`를 누르면
- **이렇게 돼요:** 선물 카드 3개가 나온다
  - 카드에는 그림 · 이름 · 가격 · 추천 이유 한 줄 · `상품 찾아보기 ↗`
  - `상품 찾아보기 ↗`를 누르면 쇼핑몰 검색이 새 창으로 열린다
- **이럴 땐:** 맞는 선물이 없으면 "조건에 맞는 선물이 없어요"가 나온다
- **먼저 필요한 것:** 1번, 선물 목록

### 3. ＋ 2개 더

- **어디서:** 카드 목록 맨 끝
- **이렇게 하면:** `＋ 2개 더`를 누르면
- **이렇게 돼요:** 아직 안 본 선물 2개가 아래에 붙는다
- **이럴 땐:** 더 보여 줄 선물이 없으면 버튼이 사라진다
- **먼저 필요한 것:** 2번

### 4. 더 보기

- **어디서:** 각 카드 아래
- **이렇게 하면:** `더 보기`를 누르면
- **이렇게 돼요:** 카드가 펼쳐지고 추천 이유가 2~3줄로 자세히 나온다
- **이럴 땐:** 다시 누르면 접힌다
- **먼저 필요한 것:** 2번

### 5. 다시 고르기

- **어디서:** 카드 목록 아래
- **이렇게 하면:** `다시 고르기`를 누르면
- **이렇게 돼요:** 조건 고르는 곳으로 올라간다. 전에 고른 건 남아 있어서 바꿀 것만 누르면 된다
- **먼저 필요한 것:** 1번

### 6. 찜하기

- **어디서:** 각 카드 오른쪽 위 ♡, 화면 위쪽 `찜`
- **이렇게 하면:** 카드의 ♡를 누르면
- **이렇게 돼요:** ♥로 바뀌고 "찜했어요"가 잠깐 나온다. 위쪽 `찜 2`를 누르면 찜한 선물만 모아서 볼 수 있다
- **이럴 땐:**
  - 다시 누르면 찜이 풀린다
  - 브라우저에 저장돼서 새로고침해도 남아 있다. 다른 휴대폰이나 PC에서는 안 보인다
- **먼저 필요한 것:** 2번

### 7. 결과 공유하기

- **어디서:** 추천 결과 제목 옆
- **이렇게 하면:** `공유하기`를 누르면
- **이렇게 돼요:** 고른 조건이 담긴 링크가 복사되고 "링크를 복사했어요"가 나온다. 받은 사람이 링크를 열면 같은 조건으로 추천이 나온다
- **이럴 땐:**
  - 휴대폰에서는 카카오톡 등으로 바로 보내는 공유 창이 열린다
  - 받은 사람에게는 같은 조건의 다른 선물이 나올 수도 있다
- **먼저 필요한 것:** 2번

### 나중에 (지금은 안 만듦)

상황별 선물 · 자주 묻는 질문

## 04. 저장되는 데이터

**사용자가 글자를 입력하는 칸은 없다.** 회원가입도 없다.
고른 조건은 새로고침하면 사라지고, **찜한 선물만 브라우저에 저장된다.**

### 선물 목록 (사이트에 미리 넣어 둠, 60개 정도)

| 항목 | 타입 | 비고 |
| --- | --- | --- |
| `id` | 숫자 | 선물 번호 (찜하기에 사용) |
| `name` | 글자 | 선물 이름. 예: 핸드드립 세트 |
| `who` | 목록 | 누구에게 (여러 개 가능) |
| `budget` | 선택 1개 | 예산 4개 중 하나 |
| `occasion` | 목록 | 어떤 날 (여러 개 가능) |
| `keywords` | 목록 (2개) | 키워드. 예: #실용적, #고급스러운 (05 참고) |
| `price` | 글자 | 가격. 예: 약 4만 원대 |
| `reason` | 글자 | 추천 이유 한 줄 (카드) |
| `detail` | 글자 | 추천 이유 자세히 (`더 보기`) |

- 조건마다 선물이 5개 이상 있으면 `＋ 2개 더`까지 잘 동작한다

### 찜한 선물 (브라우저에 저장)

| 항목 | 타입 | 비고 |
| --- | --- | --- |
| `gift_id` | 숫자 | 찜한 선물 번호 (선물 목록의 `id`) |
| `saved_at` | 날짜·시간 | 찜한 때. 최근 찜한 순서로 보여 줄 때 사용 |

## 05. 키워드와 선물 목록 프롬프트

### 키워드 8개

| 키워드 | 뜻 | 예시 선물 |
| --- | --- | --- |
| #실용적 | 매일 쓰는 물건 | 텀블러, 무선 충전기 |
| #감성적 | 분위기와 마음을 전하는 물건 | 캔들, 드라이플라워 |
| #고급스러운 | 받았을 때 격이 느껴지는 물건 | 만년필, 브랜드 핸드크림 |
| #가성비 | 가격보다 좋아 보이는 물건 | 디퓨저, 머그잔 세트 |
| #건강 | 몸을 챙겨 주는 물건 | 마사지기, 차 세트 |
| #휴식 | 쉬는 시간을 선물하는 물건 | 입욕제, 수면 안대 |
| #오래 쓰는 | 몇 년 두고 쓰는 물건 | 가죽 지갑, 우산 |
| #취향 | 받는 사람 취미에 맞춘 물건 | 원두 세트, 책 |

### 상황별 어울리는 키워드

| 어떤 날 | 잘 맞는 키워드 | 이유 |
| --- | --- | --- |
| 생일 | #취향 · #오래 쓰는 | 그 사람을 잘 아는 날이라서 |
| 기념일 | #감성적 · #고급스러운 | 특별한 날을 기억하게 하려고 |
| 감사 | #가성비 · #감성적 | 부담은 적게, 마음은 분명하게 |
| 집들이 | #실용적 · #감성적 | 새 집에 바로 놓아 둘 수 있게 |
| 축하 | #실용적 · #고급스러운 | 새 출발에 쓸 수 있는 좋은 물건 |
| 응원 | #휴식 · #건강 | 지친 사람에게 쉼을 주려고 |

**페르소나에 적용하면**
- **지은 씨:** 선배 승진 축하 → #실용적 · #고급스러운
- **도현 씨:** 친구 집들이 → #실용적 · #감성적. "싸 보이지 않게"가 중요하니 #가성비도 함께 본다
- **민서 씨:** 엄마 생신 → #오래 쓰는. 부모님이 잘 쓸 수 있어야 하니 #건강도 함께 본다

### 선물 목록 만들기 프롬프트 (그대로 복사해서 붙여 넣기)

```
Gift Finder 선물 추천 사이트에 넣을 선물 목록을 표로 60개 만들어 줘.

[키워드]
선물마다 아래 8개 중에서 2개를 골라 붙여 줘. 이 외의 키워드는 쓰지 마.
#실용적 #감성적 #고급스러운 #가성비 #건강 #휴식 #오래 쓰는 #취향

[상황별 어울리는 키워드]
- 생일: #취향, #오래 쓰는
- 기념일: #감성적, #고급스러운
- 감사: #가성비, #감성적
- 집들이: #실용적, #감성적
- 축하(취업·승진): #실용적, #고급스러운
- 응원: #휴식, #건강
선물의 "어떤 날"을 정할 때, 그 선물의 키워드가 위 상황과 하나 이상 겹치게 해 줘.

[표의 칸]
id(번호) | name(선물 이름) | who(누구에게, 여러 개) | budget(예산 1개) | occasion(어떤 날, 여러 개) | keywords(키워드 2개) | price(가격대) | reason(추천 이유 한 줄) | detail(추천 이유 자세히)

- who: 연인 · 친구 · 부모님 · 직장 동료 · 형제자매 · 나에게
- budget: 3만 원 이하 · 3~5만 원 · 5~10만 원 · 10만 원 이상
- occasion: 생일 · 기념일 · 감사 · 집들이 · 축하 · 응원
- price: "약 4만 원대"처럼
- reason: 20~30대가 읽기 편한 차분한 말투로 한 줄. 키워드가 왜 맞는지 드러나게
  (예: #실용적 → "매일 책상에서 쓰기 좋아요")
- detail: 2~3줄. 어떤 사람에게 좋은지, 고를 때 팁 한 가지

[조건]
- "누구에게 × 예산" 조합마다 선물이 5개 이상 있게 해 줘
- 8개 키워드가 골고루 쓰이게 해 줘 (한 키워드가 전체의 20%를 넘지 않게)
- 실제로 쇼핑몰에서 찾을 수 있는 흔한 선물로 해 줘 (특정 브랜드 이름은 빼 줘)
```

### 사이트 추천 규칙에 더할 한 줄 (선택)

```
추천할 때, 고른 "어떤 날"에 어울리는 키워드를 가진 선물을 먼저 보여 주고, 카드에 키워드 2개를 태그로 표시해 줘.
```

## 06. 컬러 테마

- **메인 배경:** 아이보리 `#F7F5EF`
- **선물 이모티콘 배경:** 웜 베이지 `#E9E3D5`, 세이지 그린 `#E3E8DA`, 더스티 로즈 `#F0E1DC`, 더스티 블루 `#E2E8ED`를 카드마다 번갈아 적용해 줘.
- **카드 본문:** 화이트 `#FFFFFF`
- **포인트 컬러:** 올리브 그린 `#78856A`
- **디자인 스타일:** 선물 이모티콘은 중앙에 크게 배치하고, 배경색은 은은하게 사용해 줘. 카드 모서리는 둥글게 처리하고 여백을 충분히 확보해 줘.
- **전체 분위기:** 20~30대를 위한 깔끔하고 세련된 미니멀 디자인으로 만들어 줘.
